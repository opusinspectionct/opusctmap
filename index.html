How to use this map

  • Layers: Each checkbox in the top-right panel is one category of station (Current, Waiting List, Out of Program, etc). Uncheck one to hide those pins.
  • Colors: Each layer has its own pin color, shown next to its name in that panel.
  • Pin details: Click any pin to see the station's full info — address, status, contact, comments.
  • Background: Use the Light / Dark / Satellite buttons to switch the map style. The Connecticut state outline and town borders adjust their color automatically so they stay visible on any background.
  • Loading: When the page first opens, it looks up every address one at a time (takes a few minutes). The progress bar top-left shows how far along it is.
  • Problem addresses: A small number of addresses can't be auto-located. Once loading finishes, a red count and list appear right in this panel so they can be fixed in the source sheet.
